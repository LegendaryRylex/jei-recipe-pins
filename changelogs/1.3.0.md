# Added

- AE2 network awareness for pinned recipes: items stored in the network count towards an input while an ME terminal is open, or anywhere while a linked wireless terminal on you is in range and the server also has the mod. Matching terminal entries are highlighted, and inputs the network can only autocraft are tinted blue instead of red.

# Changed

- Pin show/hide button, moved to the bottom left corner beside JEI's buttons when there is room and beside the open GUI otherwise, and rebuilt on the public JEI API so the mod no longer patches JEI internals.
- Show/hide and layout editor keybinds, now unbound by default instead of Alt+P and P; set them in Controls.

# Fixed

- JEI overlay placement around pins beside the GUI and the FTB Library sidebar: the whole side a pin reaches into is kept clear, so JEI no longer squeezes in next to it.
